# nubl-ebtikar.online — صفحة نجمة نُبل وابتكار (اليوم الوطني 96)

الموقع الحي: https://nubl-ebtikar.online/

النشر تلقائي عبر Cloudflare Pages: كل دفعة (push) إلى الفرع `main` تُنشر على النطاق خلال دقيقة.

## البنية
- `index.html` — الصفحة الكاملة (RTL، باقات اليوم الوطني 96، الأطباع الستة، مشغّل الأغاني الوطنية، الكتالوج).
- `nd/` — أصول هوية «عزّنا بطبعنا» المستخرجة من ملفات الهيئة العامة للترفيه (رموز الأطباع، النقوش، الصورة الرئيسية، شعار الحملة).
- `nd/audio/` — يُترك فارغاً؛ إن وُضعت فيه ملفات `mawedna-2030.mp3` و`foq-al-sahayeb.mp3` و`wenaam.mp3` يشغّلها الموقع محلياً بدل جلبها من CDN الهيئة.
- `catalog/` — كتالوج الباقات (PDF + صور الصفحات للعارض).
- `_headers` — إعدادات التخزين المؤقت لـ Cloudflare Pages.

## التحديث
عدّل `index.html` أو الأصول ثم:
```
git add -A && git commit -m "وصف التعديل" && git push
```
