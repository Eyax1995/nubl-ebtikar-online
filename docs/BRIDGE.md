# الجسر بين Cowork وClaude Code

يتيح هذا الملف لجلستَي Cowork (التخطيط) وClaude Code (التنفيذ) العمل على مستودع واحد دون نسخ ولصق. المستودع هو الذاكرة المشتركة بينهما.

## التقسيم
- **Cowork:** يكتب المواصفات ويراجع التنفيذ. يصل إلى هذا المجلد مباشرة على جهاز إياد.
- **Claude Code:** ينفّذ ويختبر ويعمل commit ثم ينشر.

## الملفات
- `docs/specs/<الاسم>.md`: مواصفة يكتبها Cowork، ولا يعدّلها Claude Code إلا لتصحيح خطأ واضح.
- `docs/specs/<الاسم>.status.md`: ملف الحالة، يكتبه Claude Code ويحدّثه بعد كل جلسة عمل.
- `CLAUDE.md` و`docs/HANDOFF.md`: المرجع الدائم للبنية والقرارات.

## قالب ملف الحالة (يلتزم به Claude Code)
```
# حالة: <الاسم>
آخر تحديث: <التاريخ والوقت> — آخر commit: <hash>
## منجز
- [x] البند … (commit …)
## قيد العمل
- [ ] …
## نتائج معايير القبول
1. ✅/❌ …
## أسئلة لـ Cowork
- …
## ملاحظات للنشر
- …
```

## الدورة
1. يطلب إياد في Cowork ميزة جديدة، فيكتب Cowork `docs/specs/<الاسم>.md` في المستودع.
2. في Claude Code يكتب إياد: `نفّذ docs/specs/<الاسم>.md وفق docs/BRIDGE.md`.
3. ينفّذ Claude Code، ويختبر، ويحدّث ملف الحالة، ويعمل commit، وينشر إذا نجحت معايير القبول.
4. في Cowork يكتب إياد: `راجع تنفيذ <الاسم>`. يقرأ Cowork ملف الحالة وسجل git والفروقات، ثم يرد بأحد أمرين:
   - اعتماد الميزة.
   - مواصفة متابعة: `docs/specs/<الاسم>-2.md`.
5. أسئلة Claude Code تُكتب في ملف الحالة لا في المحادثة، ويجيب عنها Cowork في المواصفة التالية.
